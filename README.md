# C++ Data Structures Assignments

A collection of C++ programs implementing core data structures and algorithms,
written as coursework at MIT Academy of Engineering. Each program is menu-driven
or interactive and includes sample output.

## Contents

| # | Topic | Concepts |
|---|-------|----------|
| 1 | Student Marks Analysis | Arrays, total / average / highest / lowest, above-average filtering |
| 2 | Phonebook Management | Structs, bubble sort by name, search, sorted insertion |
| 3 | Parking Slot Allocation | Hash table with linear probing |
| 4 | Music Playlist Management | Circular linked list (add, display, delete) |
| 5 | Infix to Postfix Conversion | Stack, operator precedence |
| 6 | Postfix Expression Evaluation | Stack (STL) |
| 7 | Stack Using Linked List | Push, pop, peek, display |
| 8 | Customer Service System | Circular queue (array-based) |
| 9 | Double Ended Queue | `priority_queue` based implementation |
| 10 | Student Record Management | Binary search tree: insert, search, delete, min/max, predecessor/successor, inorder / preorder / postorder traversals |

## Tech

- Language: C++
- Compiler: g++ (tested on OnlineGDB and VS Code)

## How to Run

```bash
g++ filename.cpp -o program
./program
```
